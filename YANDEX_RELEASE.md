# Подготовка к Яндекс Играм · 23 октября 2026

Техническая подготовка репозитория и локальные проверки. Это не результат
автоматической проверки Яндекса и не подтверждение прохождения модерации.
Официальные страницы документации в рабочей среде отвечали HTTP 403;
актуальные требования необходимо сверить в кабинете перед отправкой.

## Что реализовано

- SDK загружается с `/sdk.js` на доменах Яндекса. Для локального тестового
  стенда включается параметром `?yandex=1`; на GitHub Pages SDK не запрашивается.
- `YaGames.init()`, однократный `features.LoadingAPI.ready()` после готовности
  движка, загрузки страницы и шрифтов. Вызов не привязан к нажатию игрока.
- `features.GameplayAPI.start()/stop()` при игре, выходе, результате,
  обучении, открытии модальных окон, потере фокуса и паузе платформы.
- `game_api_pause` / `game_api_resume`, скрытие вкладки и потеря фокуса
  останавливают ввод, звук, игровое время, отложенные действия и уже
  запущенные анимации. При возврате задержки продолжаются с оставшегося времени.
- Прогресс записывается после действий; уход со страницы не перезаписывает
  уже импортированное сохранение. Сохранения
  локальные; облачной синхронизации аккаунта и авторизации SDK нет.
- Шрифты Manrope и Cormorant Garamond находятся в архиве, с лицензиями SIL OFL.
  Google Fonts во время запуска не запрашивается. В SDK нет сторонней аналитики.
- Два общих блока экрана выровнены; поле и персонаж адаптируются к размеру
  экрана. Есть управление мышью, касанием, свайпами и клавиатурой.
- Контекстное меню, выделение и перетаскивание игровых изображений отключены;
  ввод текста и импорт сохранения сохраняют стандартное поведение.
- В игре нет платёжного SDK, рекламы, реальных ставок или вывода средств.
  Ларцы расходуют только заработанную игровую пыль, шансы показаны в гардеробе.

## Архив

`npm run build:yandex` создаёт `dist/zodiak-yandex.zip` и отчёт
`dist/package-report.json`. В корне ZIP находится `index.html`; изображения,
шрифты, CSS и JavaScript включены. Сборщик проверяет стартовые ссылки,
целостность ZIP и исключение тестов, node_modules, пользовательских данных.
Архив не коммитится. GitHub Actions `Package for Yandex Games` запускает
тесты и публикует артефакт `yandex-games-package` после push в main.

## Проверка в черновике платформы

1. Создать/открыть приложение в кабинете разработчика и загрузить ZIP.
   Для текущей версии выбрать русский язык интерфейса. Подготовить реальные
   скриншоты, обложку, описание и возрастную маркировку по правилам кабинета;
   эти материалы ещё не входят в репозиторий.
2. В черновике проверить `GamePlatform.state`: `sdk: connected`, `ready: true`,
   отсутствие `readyError`, `gameplayError`. В инструментах платформы проверить
   последовательность loading ready / gameplay start / gameplay stop.
3. Проверить все три режима, обучение, победу/поражение, уход на другую
   вкладку, паузу платформы, возвращение во время тасовки и каскада.
   В фоне звук и игра должны останавливаться; пользовательское выключение
   звука должно сохраняться после возвращения.
4. Проверить мобильный iframe, оба поворота устройства, маленькое окно,
   отсутствие обрезанных кнопок и прокрутки страницы портала.
5. Завершить несколько уровней, применить наряд и питомца, перезагрузить
   черновик: прогресс должен сохраниться в том же браузере. Очищенная
   память браузера и другое устройство не восстанавливают локальный прогресс.
6. Запустить автоматическую проверку Яндекса и передать её отчёт для
   устранения конкретных замечаний, затем отправить на ручную модерацию.
   Права на графику/оформление и материалы карточки приложения подтверждает
   издатель; локальные тесты это не проверяют.
