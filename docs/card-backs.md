# Рубашки и магазин

16 утверждённых рисунков заменяют прежние CSS-узоры. Техники и материалы
различаются: гравюра, металл, неон, акварель, ретропечать, дерево, обсидиан,
кружево, кристалл, линогравюра, лак, бумажная аппликация, вышивка, лёд и глина.

В магазине — крупная карточка с изображением, названием, материалом,
ценой или условием получения. Купленный предмет можно надеть без повторной
оплаты. Та же графика используется в гардеробе и окне награды.

| Новая рубашка | Звёзды |
|---|---:|
| Воронье перо | 180 |
| Печать дракона | 340 |
| Лунный сад | 220 |
| Сердце Оракула | 240 |
| Ледяная корона | 300 |
| Тыквенная ночь | 220 |

Старые цены сохранены. «Заря», «Мох», «Бездна» остаются наградами календаря,
«Розовый кварц» — за обучение, «Небесный» — за коллекцию. Их нельзя купить
в обход наградных условий. Классика доступна с начала игры.

Один выбранный файл используется на всех закрытых картах. Пропорции рисунка
сохраняются, даже при повороте телефона. Переворот, подсветка цели, анимации,
механики и лицевые стороны не изменены. Карточные уровни бесконечного режима
используют ту же рубашку. В «Три в ряд» рубашек нет.

ID старых предметов сохранены, миграция/сброс прогресса не требуются. Общий
каталог используется в UI и при проверке сохранений; новые покупки проходят
импорт и проверку облачного пакета. Названия и описания переведены на RU/EN/TR.

Производственные файлы — WebP с альфа-каналом (около 770 КБ на всю коллекцию).
PNG-оригиналы и скриншоты не включаются в архив игры.
