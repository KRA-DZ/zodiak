# Исправление `320 map` в GitHub Actions

В журнале запуска 934b18b: 140 успешных тестов, один сбой —
`small phones and rotated phones keep map targets, game boards and controls within the viewport`,
сообщение `320 map`. Пакетирование и загрузка ZIP не запускались, поскольку
проверки не прошли. Предупреждения о Node.js не были причиной этого сбоя.

Координаты компактной карты ранее выбирались по высоте окна, хотя реальная
область карты меньше на заголовок, панели и кнопки. Проценты также не
резервировали фиксированный размер области касания. Различия в шрифтах,
высоте панелей и моменте нативной раскладки могли приводить к выходу
кнопок за границу либо пересечениям.

Теперь координаты вычисляются по clientWidth/clientHeight viewport карты.
Зарезервированы края под кнопки 44×44 и короны. В короткой области
используется компактная змейка, в совсем короткой — два ряда по пять.
Длинная карта сохраняет извилистую линию. ResizeObserver
обновляет существующие кнопки и SVG-линию при изменении области.
Прогресс при этом не сохраняется повторно и DOM не пересоздаётся.

Тест продолжает требовать все десять кнопок внутри карты без пересечений.
Дополнительно проверяются горизонтальные границы. Ожидание нативной
раскладки ограничено; при сбое в журнал попадают полные координаты.
Новый сценарий меняет перевод и высоту заголовка при неизменном окне
320×480, проверяя реальный пересчёт области.

Журнал npm test сохраняется в `automated-test-log` при любом исходе запуска.
Падение тестов по-прежнему останавливает создание игрового ZIP. Проверки
не отключаются и результат ошибки не превращается в успешный.

Локальные браузерные проверки выполняются в установленном Chromium 154.
GitHub использует браузер Playwright 151; его загрузка и удалённый API GitHub
в этой среде недоступны. Поэтому успешный статус нового удалённого запуска
нужно проверить в Actions, а не выводить из локального результата.

Проверочные кадры:

- [320×480](mobile-map-ci-preview/phone-320.png)
- [320×660](mobile-map-ci-preview/phone-middle.png)
- [852×343](mobile-map-ci-preview/landscape.png)

В проверке музыки также устранена гонка с первым окном календаря: тест
дожидается его появления и закрывает окно перед проверкой выхода в меню.
Игровой календарь и музыка не изменены.
