# Созвездие памяти

Браузерная игра без сборки. Для локального запуска выполните из корня
репозитория `python3 -m http.server 8000` и откройте `/index.html`.

## Проверки

Требуется Node.js 20 или новее:

```sh
npm ci
npx playwright install chromium
npm test
```

Если Chromium уже установлен в системе:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

Тесты запускают игру в браузере, проверяют завершение уровня, сохранение
прогресса, досрочное завершение показа карт и отмену анимаций при выходе.
Также проверяются отрисовка всех 84 уровней, тасовка «Оракула»,
астро-карта и запуск уровня через интерфейс на мобильном экране.
Внешние шрифты и другие сетевые ресурсы в тестах отключены.
