# Созвездие памяти

Мистическая браузерная игра про гороскопы: память, внимание и алхимия звёзд.
Все изображения карт и фона из исходного проекта сохранены. Сборка и серверная
часть не требуются, игра работает на GitHub Pages.

Для локального запуска из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте `/index.html`. Для GitHub Pages выберите **Settings → Pages → Deploy
from a branch → main → /(root)**.

## Краткий экскурс

- **Продолжить путь** — следующий открытый уровень выбранного знака.
- **Звёздный атлас** — 12 карт с исходными иллюстрациями, по 9 уровней на знак,
  всего 108. Первые 7 сохраняют прежние механики пар, триад, обманок, тёмных карт,
  боссов и Оракула; уровни 8–9 добавляют «три в ряд».
- **Зал алхимии** — «три в ряд» доступно сразу, вне кампании. Обменяйте соседние
  символы: линия из 3 исчезает, комбинация 4+ даёт один дополнительный ход.
  Неудачный обмен не расходует ход. Каскады и бесплатная перетасовка тупиков
  поддерживают игровой процесс. Подсказка отмечает возможный обмен.
- **Бесконечное небо** — чередует пары, Оракула и алхимию. Сложность растёт до
  ограниченного предела. Награды и номер следующего этапа сохраняются после
  каждой победы; незавершённое поле при выходе начинается заново.
- **Ритуал дня** — 3 победы в любых режимах дают 50 пыли и печать Оракула.
  Награда доступна раз в местные календарные сутки, не раз в открытие страницы.
- **Календарь даров** — исходные 31 награда повторяются новым циклом. Серия
  последовательных входов даёт дополнительно от 5 до 35 пыли. Пропуск сбрасывает
  только серию входов, но не уже полученные награды или прогресс календаря.
- **Стол гадалки** — любовь, карьера, финансы и здоровье за 50 пыли или одну
  печать. Печать расходуется первой. По одному предсказанию на тему, знак и день.
  Повторный просмотр уже открытой карты бесплатен.
- **Книга предсказаний** — последние 100 купленных посланий с фильтрами по теме
  и экспортом копии прогресса в JSON. В ежедневных бесплатных прогнозах пыль не
  расходуется; они остаются отдельным разделом.

Тексты сохраняют классический гороскопный тон с лёгкой мистикой и характерными
чертами каждого знака. Добавлены 576 персонализированных вариантов к исходным
предсказаниям. Повторы в категории избегаются до исчерпания доступного пула.

## Награды и сохранения

Первое прохождение уровня кампании — 25 пыли, повторное — 10. Зал алхимии даёт
10 пыли за победу. Бесконечное небо даёт `10 + 2 × min(этап, 10)` пыли; каждый
третий этап дополнительно даёт 15 пыли и печать. Награды не пропадают при выходе.
Звёзды в алхимии зависят от оставшихся ходов: 1 за победу, 2 при остатке хотя бы
одного хода, 3 при сохранении не менее 30% исходного запаса ходов.

Данные хранятся в `localStorage` этого браузера, без аккаунта и синхронизации
между устройствами. Не очищайте данные сайта, если хотите сохранить прогресс.
Экспорт JSON создаёт резервную копию; интерфейс импорта пока не добавлен.

Старое сохранение на 84 уровня автоматически переносится на 108 без потери
звёзд, валюты, инвентаря, стилей, календаря и трофеев. После пройденного старого
7-го уровня открывается 8-й. Старая копия сохраняется под ключом
`zodiacMemory.beforeJourney`; основное сохранение остаётся `zodiacMemory.v3`.
Индексированные старые предсказания поддерживаются, новые сохраняются текстом.

## Проверки

Нужен Node.js 20 или новее:

```sh
npm ci
npx playwright install chromium
npm test
```

С системным Chromium:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

Проверки включают модель «три в ряд», перенос старого сохранения, отрисовку всех
108 уровней, прохождение и проигрыш, отмену отложенных анимаций, покупки,
архив, ежедневные награды, бесконечный режим и мобильные сценарии. Внешние
шрифты и сетевые ресурсы отключены в тестах.

## Структура

- `index.html` — исходные экраны, движок пар и Оракула, интеграция наград.
- `match3.js` — модель и контроллер алхимии.
- `journey.js` — миграция сохранений и конфигурации новых уровней.
- `predictions.js` — дополнительные тексты по знакам и категориям.
- `journey.css` — навигация, мобильные экраны и читаемые карты предсказаний.

Игра поддерживает клавиатуру и системную настройку уменьшения анимаций.
