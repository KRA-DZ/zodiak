подсказкой текущего кабинета. ZIP скриншотов не загружается как картинка:
загрузите находящиеся внутри PNG.

## Что показано в нарезке

1. Комбинации, падение фишек и каскады в «Алхимии звёзд».
2. Лунный образ с совой, затем лесной наряд с котом в гардеробе.
3. Запоминание карт и открытие пары в «Созвездии памяти».
4. Показ цели Оракула, настоящая тасовка и успешный выбор карты.
5. Раскрытие предсказания о любви для выбранного знака.
6. Альбом зодиака и анимированная коллекционная карта.

Рекламные подписи занимают отдельную полосу; изображение игры под ними
сохранено целиком. Чистые версии не содержат рекламных подписей. Монтаж
использует короткие перекрёстные переходы между эпизодами.

Порядок сцен и подписи находятся в [trailer-storyboard.json](trailer-storyboard.json).
Скриншоты показывают три игровых режима, гардероб, предсказание и альбом.
Это настоящие кадры без рекламных надписей, без дорисованных элементов.

## Языки и профиль записи

Иконка и обложка без текста подходят всем трём языкам. Видео и скриншоты
содержат русский интерфейс; рекламные версии также имеют русские подписи.
Для англоязычной/турецкой страницы при необходимости нужна отдельная запись.

Использован отдельный подготовленный демонстрационный профиль с одной
собранной картой, несколькими открытыми нарядами и питомцами. Все показанные
объекты и действия существуют в игре. Для вступления выбран обычный
случайный расклад с большой комбинацией и суперфишкой; игровые правила
и вероятности выпадения предметов не менялись. Данные игроков, механики и интерфейс
опубликованной игры не изменялись. Исходники иллюстраций сохранены в
`artwork-source/promotion/`.

## Повторная запись

Нужны зависимости проекта, Chromium Playwright и ffmpeg/ffprobe.

```sh
python3 -m http.server 8765
# В другом терминале:
npx playwright install chromium ffmpeg
node scripts/record_promotion.cjs
python3 scripts/render_promotion.py
```

`CHROMIUM_PATH` позволяет указать системный Chromium, `PROMO_WORKDIR` —
каталог промежуточных файлов. Запись разрешена только с localhost/127.0.0.1;
временный доступ к функциям добавляется перехватом HTML в браузере,
исходный index.html не изменяется. Исходные записи и промежуточные клипы
сохраняются в рабочем каталоге; перед публикацией монтаж нужно просмотреть.
При необходимости смещение видеочасов задаётся полем `videoOffset` в JSON
записи; длительность последнего повторённого кадра не используется как
смещение начала записи.

Материалы страницы и скрипты записи не входят в игровой ZIP и не увеличивают
загрузку игры. Реальную кликабельность можно оценить по показам и переходам
после публикации и сравнению разных вариантов.
