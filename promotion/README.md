# Материалы для страницы Яндекс Игр

Подготовлены 24 октября 2026 года. Персонаж, питомец и символы основаны на
существующей графике игры; иконка и обложка — новые промоиллюстрации.

| Поле кабинета | Файл | Формат |
|---|---|---|
| Иконка | [icon-512.png](icon-512.png) | PNG, 512×512, непрозрачный фон |
| Обложка | [cover-800x470.png](cover-800x470.png) | PNG, 800×470, непрозрачный фон |
| Вертикальное видео | [gameplay-vertical-720x1280.mp4](gameplay-vertical-720x1280.mp4) | MP4/H.264, 720×1280, 30 кадров/с, 23 секунды, без звука |

Картинки без текста подходят для русской, английской и турецкой страниц.
Исходные изображения высокого разрешения сохранены в
`artwork-source/promotion/`. Размеры PNG проверены после экспорта.

Ролик снят из реальной игры с обычными ходами и анимациями: «Алхимия звёзд»,
существующий наряд и кот. Для подготовки записи использовался отдельный
сеанс; код и прогресс опубликованной игры не менялись. Видео с русским
интерфейсом; для других языковых страниц при необходимости нужна отдельная
запись интерфейса соответствующего языка.

Обложка предназначена для поля обложки. Для поля скриншотов используйте
реальные кадры игры. Иконка проверена при уменьшении до 80×80, обложка —
до 320×188. Фактическую кликабельность можно оценить только по показам
и переходам после публикации и сравнению вариантов.

Эта папка и исходники не входят в ZIP игры и не увеличивают загрузку игры.
Загружайте файлы отдельно в соответствующие поля кабинета. Перед загрузкой
видео сверьте допустимые параметры в подсказке поля текущего кабинета.
