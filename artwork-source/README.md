# Оригиналы оформления

Эта папка не входит в ZIP игры и не загружается браузером.

- `assets/observatory-atlas.png` — исходный эталон стиля героев и питомцев.
- Остальные PNG, имеющие соответствующий WebP в корне проекта или `assets`,
  сохранены как исходники. Рабочие WebP закодированы без потерь: размеры,
  прозрачность и видимые RGBA-пиксели проверены на совпадение.
- `assets/zodiac-worlds-0.png` … `zodiac-worlds-2.png` — старые фоны,
  заменённые отдельными `assets/route-*.webp`.
- `assets/path-seals.png` — прежние яркие печати, заменённые тёмными.
- `shar.png` — фон старого скрытого блока предсказаний.

Исходники доступны для следующей работы над графикой. Сборка берёт только
файлы из корня проекта и рабочей папки `assets`, исключая этот архив.
Результаты сравнения размеров и пикселей — `optimization-report.json`.
